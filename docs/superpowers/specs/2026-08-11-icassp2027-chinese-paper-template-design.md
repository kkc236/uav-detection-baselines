# ICASSP 2027 中文论文模板设计规范

## 1. 目标

为无人机小目标检测研究生成一份可直接扩写、压缩并翻译为 ICASSP 2027 英文稿的中文详细底稿。论文以 Ultralytics RT-DETR-L 为基础，统一组织 FDR、BPDD 和 RA-GLGM 三个组件，并按 ICASSP 主会四页技术正文的容量约束控制叙事。

本规范采用以下规划假设：RA-GLGM 最终严格实验成功，能够在 FDR+BPDD 基础上提供稳定正增益。该假设只决定论文结构，不授权虚构结果；尚未冻结的数值必须保留为显式结果槽位。

## 2. 推荐论文定位

论文采用问题驱动而不是模块罗列式结构，围绕无人机视角下三个相互关联的困难展开：

1. 极小目标边界量化粗糙，连续四维框回归难以表达细粒度位置不确定性；
2. Decoder 各阶段候选质量不均，固定使用最终层监督会浪费更优中间轨迹；
3. 目标尺度跨度大且小目标信号弱，统一特征处理容易造成局部细节不足或背景噪声放大。

三个组件分别对应上述问题：

- FDR：将连续框点估计改为细粒度四边分布表示；
- BPDD：在训练期按目标动态选择更可靠的解码阶段并形成渐进式监督；
- RA-GLGM：通过真实尺度路由和恒等残差，在高分辨率层增强尺度适配的局部—全局表征。

统一论点为：从边界表示、优化轨迹和尺度表征三个互补维度提升 RT-DETR-L 对无人机小目标的检测能力。

## 3. 输出文件

正式模板保存为：

`docs/ICASSP2027_FDR_BPDD_RA_GLGM_CHINESE_PAPER_TEMPLATE_ZH.md`

该文件是中文内容底稿，不是排版后的最终 PDF，也不直接宣称达到投稿条件。

## 4. 文档结构

### 4.1 标题与摘要

- 提供三个英文题目候选及对应中文释义；
- 摘要按“场景困难—现有缺陷—三项方法—实验结果—效率结论”组织；
- 已有结果直接引用冻结证据；
- RA-GLGM和最终组合结果使用统一字段，例如 `【FULL_MAP】`，不得使用虚构数字。

### 4.2 引言

引言使用四段式结构：

1. 无人机检测的现实价值与小目标困难；
2. RT-DETR 的速度优势及其在细粒度定位、解码监督和尺度适配方面的局限；
3. 本文统一方法及三个组件的因果关系；
4. 三条贡献声明。

FDR 的贡献边界必须明确为面向 Ultralytics RT-DETR-L 与 VisDrone 的结构化适配和统一验证，不得宣称原创 D-FINE 的 FDR、FGL 或 Integral 基础机制。

### 4.3 相关工作

相关工作压缩为三组：

- DETR/RT-DETR 实时检测；
- 无人机小目标与尺度增强；
- 分布回归和解码器监督。

该部分只保留与方法动机或对照实验直接相关的工作，防止挤占四页正文。

### 4.4 方法

方法部分按以下顺序展开：

1. Overall Architecture：给出训练路径、推理路径和三个组件位置；
2. FDR：preliminary box、六层累计分布预测、Integral 解码和 FGL；
3. BPDD：候选轨迹、质量准则、动态教师选择、门控混合及训练期损失；
4. RA-GLGM：P3 插入位置、局部/全局分支、真实尺度门控和恒等残差；
5. Unified Objective：汇总原生检测损失、FGL、pre-box监督和BPDD监督。

模板必须明确：BPDD 为训练期优化组件，部署图与普通 FDR+RA-GLGM 一致；FDR 和 RA-GLGM 影响推理网络。

### 4.5 实验

实验部分包含：

- 数据集、硬件和统一协议；
- 与原版 RT-DETR-L 及相关方法的主结果；
- `Control / FDR / FDR+BPDD / FDR+RA / Full` 核心消融；
- BPDD机制消融；
- RA-GLGM尺度门和插入位置消融；
- APtiny/APsmall/APmedium/APlarge；
- 10类结果；
- 参数、GFLOPs、FP16延迟和显存；
- 典型成功案例和失败案例。

表格字段采用可替换变量，并附证据来源说明。未经严格闭环的结果只允许出现在“待填字段”，不得写入结论句。

### 4.6 结论

结论只复述已被最终实验证实的贡献和代价，不使用“全面解决”“显著优于所有方法”等超出证据的措辞。

## 5. 四页内容预算

计划按照以下比例压缩：

- 摘要：约 150–180 英文词对应的中文底稿；
- 引言与贡献：约 0.75 页；
- 相关工作：约 0.25 页；
- 方法：约 1.45 页；
- 实验与分析：约 1.35 页；
- 结论：约 0.20 页；
- 参考文献放入允许的参考文献页。

方法图最多一张主图，实验表优先采用一张主表和一张紧凑消融表。尺度与逐类别结果在版面不足时转为折线/热图或补充材料，而不是全部塞进正文。

## 6. 图表设计

### 6.1 主方法图

主图采用从左到右的数据流：

`Backbone/Encoder -> RA-GLGM at P3 -> Transformer Decoder -> FDR heads -> predictions`

训练期在 Decoder 与损失之间增加 BPDD 虚线分支。图中用实线表示推理路径，用虚线表示仅训练路径，从视觉上证明 BPDD 不增加部署开销。

### 6.2 实验表

主表报告 Precision、Recall、AP50、AP75、mAP50-95、参数和延迟。消融表使用五组配置：

| FDR | BPDD | RA-GLGM | 目的 |
|---|---|---|---|
| × | × | × | 原版基础模型 |
| ✓ | × | × | FDR 独立贡献 |
| ✓ | ✓ | × | BPDD 增量贡献 |
| ✓ | × | ✓ | RA-GLGM 增量贡献 |
| ✓ | ✓ | ✓ | 完整模型与协同性 |

必须有 `FDR+BPDD` 与 `FDR+RA-GLGM` 两个单独组合，否则无法证明两个小模块的独立作用。

### 6.3 定性案例

预留四类案例：

- 高空视角下极小行人；
- 道路密集车辆；
- 遮挡和相互邻接目标；
- 复杂背景或尺度突变场景。

每个案例统一展示 GT、RT-DETR-L、FDR 和 Full Model；案例必须由固定选择规则产生，不得只挑最有利样本。

## 7. 证据状态标记

模板采用三类标记：

- `【已冻结】`：可追溯至 checkpoint、评估 JSON、协议和 SHA256；
- `【初步参考】`：存在正向结果，但并非完整严格配对；
- `【待填】`：尚无可引用证据，只是论文结构占位。

英文成稿前必须删除全部状态标记，并将所有 `【待填】` 替换为冻结证据或删除相关结论。

## 8. 允许与禁止的贡献表述

允许：

- “we adapt fine-grained distribution regression to Ultralytics RT-DETR-L”；
- “we introduce a target-wise progressive decoder distillation strategy”；
- “we design a scale-routed local-global module for high-resolution UAV features”；
- “the three components address complementary representation and optimization limitations”。

禁止：

- 宣称原创 D-FINE 的 FDR/FGL/Integral；
- 将未经严格配对的 BPDD 数值写成最终结论；
- 在 RA-GLGM 证据未闭环时宣称稳定提升；
- 将单数据集、单 seed 结果表述为普适性能保证；
- 在没有同机 benchmark 时宣称实时性完全不受影响。

## 9. 验收标准

模板完成后必须满足：

1. 三个模块形成一条问题驱动的因果链，而不是并列堆叠；
2. FDR原创性边界准确；
3. 所有现有指标与冻结材料一致；
4. 未完成结果全部使用显式字段，不出现伪造数值；
5. 主结果、消融、尺度、类别和效率指标均有位置；
6. 可以直接按段落翻译为英文稿；
7. 结构能够压缩到 ICASSP 四页技术正文。

## 10. 后续步骤

用户确认本设计后，创建实施计划，再依据已有证据生成中文详细论文模板。模板生成不等于论文已经满足投稿条件；正式成稿仍需等 RA-GLGM 与完整模型的严格实验、配对消融和效率审计闭环。
