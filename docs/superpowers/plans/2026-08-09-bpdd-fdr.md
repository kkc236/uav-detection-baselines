# BPDD FDR RT-DETR-L Implementation Plan

> **Goal:** Add an isolated, training-only BPDD loss to the validated FDR
> RT-DETR-L implementation, prove exact FDR inference/checkpoint compatibility,
> and execute the frozen Screen30-to-Formal100 protocol with immutable evidence.

> **Architecture:** BPDD is a parameter-free loss component. It builds a
> detached GT-conditioned mixture of later FDR corner distributions for each
> final-stock-matched Query edge, applies a bounded better-only reliability
> weight, and backpropagates only through the current student distribution. A
> separate YAML and protocol keep ordinary FDR as the exact ablation.

> **Tech stack:** Python 3.10, PyTorch 2.5.1+cu121, Torchvision 0.20.1+cu121,
> Ultralytics 8.4.90, pytest, RTX 4090, Git/GitHub Release evidence pipeline.

> **Agentic execution note:** execute task-by-task with review checkpoints. Code
> workers may receive disjoint test/document slices; the main agent owns loss
> math, criterion integration, protocol authority, deployment, and final review.

### Step 2: Implement validation and target edge NLL

Implement a frozen `BPDDOptions` dataclass and small functions for interpolated
two-bin NLL. Use `torch.log_softmax`, exact left-bin/weight shapes, and explicit
finite checks. Freeze `weight=0.5`, `temperature=0.5`, `margin=0.02`, and
`eps=1e-6`.

Run the focused tests and expect GREEN for validation/NLL only.

### Step 3: Write failing teacher-detach and reliability tests

Cover:

- future softmin weights sum to one;
- no current/past layer enters a teacher;
- later teacher probabilities and selection weights are detached;
- equal/worse teacher gives exact zero reliability;
- better teacher gives bounded positive reliability;
- changing `temperature` changes only teacher mixing;
- empty matches return graph-connected zero.

### Step 4: Implement teacher and loss

Implement:

```python
pi = softmax(-future_nll.detach() / temperature, dim=0)
teacher = (pi.unsqueeze(-1) * future_prob.detach()).sum(dim=0)
reliability = ((student_nll.detach() - teacher_nll.detach()) /
               student_nll.detach().clamp_min(eps)).clamp_(0, 1)
loss = weight * (reliability * kl_teacher_student).mean()
```

Subtract the frozen margin from the numerator before clamping. Normalize over
all eligible matched student edges, not only active edges.

Return detached statistics: active-edge ratio, mean reliability, mean positive
teacher improvement, match count, and supervised-edge count.

### Step 5: Verify gradients and edge cases

```powershell
python -m pytest tests/test_bpdd_loss.py -q
```

Expected: all BPDD math tests pass; only student paths have gradient through the
distillation branch.

### Step 6: Commit

```powershell

git commit -m "feat: add better-progressive distribution distillation loss"
```

## Plan self-review

- The plan does not mutate the frozen FDR protocol or use a stock RT-DETR
  baseline for the BPDD effect.
- BPDD is one scientific variable and has no inference branch or parameters.
- Tests precede each implementation step and include explicit RED verification.
- Final-layer stock matching is reused; no matching union, unmatched, or DN
  distillation is permitted.
- Screen and formal runs start fresh, and final-epoch rules address the observed
  early-positive/late-negative failure pattern.
- Scientific failure remains publishable evidence and never authorizes lowering
  a threshold or mislabeling borrowed mechanisms as original.
