# LRS-FGL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Layerwise Reliability Shrinkage to Clean FDR's normal-query FGL weights, prove that the disabled and final-layer paths are legacy-identical, pass a frozen Gate0 diagnostic, and launch one matched Formal100 seed-0 run.

**Architecture:** Keep the FDR decoder, matcher, stock VFL/L1/GIoU, denoising path, checkpoints, and inference graph unchanged. A pure loss helper shrinks detached matched IoUs toward their same-image eligible mean at shallow decoder layers with `alpha_l = alpha0 * (1 - l / (L - 1))`; a fixed representability firewall excludes matches with any boundary-saturated FDR target edge. The criterion applies the transform only to normal decoder FGL, before repeating the scalar box weight over four edges. Configuration and launch metadata make the opt-in explicit and auditable.

**Tech Stack:** Python 3.11, PyTorch, Ultralytics 8.4.90, pytest, YAML, Git, Formal100 VisDrone protocol.

- [ ] LRS is one loss-only module, with no parameters and no inference or checkpoint-schema change.

- [ ] Same-image, same-layer sums are conserved within `2e-6` and no cross-image mixing occurs.
- [ ] Only normal decoder FGL changes; DN-FGL, EAW, decoder, matcher, VFL, L1, and GIoU remain unchanged.
- [ ] Gate0 passes without post-hoc tuning before the Formal100 run begins.
- [ ] Formal run is a strict paired Clean FDR ablation under the same initial state, data, seed, optimizer, batch size, image size, and epoch count.
